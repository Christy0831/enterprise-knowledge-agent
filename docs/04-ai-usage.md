# 04 · AI辅助开发记录

## 分工与使用范围

项目使用Codex协助需求拆解、代码实现、测试、调试和文档整理。具体修改通过代码差异、测试结果与运行Trace验证。

提交者确定第三题、DeepSeek生成模型、DashScope向量模型及React界面的需求，负责配置模型服务和GitHub仓库。代码编写与后续修正主要通过Codex协助完成，具体调整见下方记录。密钥保存在本机 `.env`，仓库提供空配置模板。

## 辅助内容与验证方式

| 内容 | 工作内容 | 验证方法 |
| --- | --- | --- |
| 原生Agent循环 | 工具调度、错误反馈、预算和输出校验 | 执行器单元测试、实际CLI运行 |
| 模型接口 | OpenAI与DeepSeek Responses适配 | 官方文档、本机HTTP合同测试与实际API验收 |
| 检索工具 | 中文二元字符/英文词BM25及原文读取 | 文档命中、截断标记、故障与快照测试 |
| 合成数据 | 有冲突及无冲突制度、产品说明、45天替换快照 | 与验收输入逐项核对；不含真实企业资料 |
| Mock与测试 | 规则替身、11类用例、自动结果存档 | 离线回归、故障注入及真实模型对照 |
| 混合检索 | DashScope向量、BM25/RRF、缓存与降级 | 融合单元测试及真实严格混合验收 |
| React界面 | 问答页面、SSE解析、引用展示与取消 | 前端解析、浏览器测试与实际流式运行 |
| 文档 | 需求、方案、评估、复盘与运行步骤 | 依据源代码和实际报告复核 |

## 修改与验证记录

1. 初次Mock扩展查询误召回无关制度，导致资料外问题被回答。根据失败Trace去掉泛化领域词，并保留初次失败证据。
2. 接入DeepSeek时按官方兼容表调整参数，增加多工具调用逐次计数、同轮调用标记及finish独占轮次约束。
3. 调整评估断言，允许真实模型首次检索前就改写同义问题，不要求其复刻Mock的固定步骤数。
4. 修正空字典/空字符串历史被误当作空数组的问题，并加入输入验证回归。
5. 第一轮真实验收发现冲突未补查，增加查证校验和回归测试；随后复核发现无依据的“专门制度优先”建议，调整提示并重新验证。
6. 回答中的引用标记曾未完整映射到结构化引文，增加对应关系校验和回归测试，保留第四轮记录。
7. 相似问法在无冲突快照中过度追问，明确同义问题与来源限定规则，保持验收状态不变，并将DeepSeek温度设为0后复测。
8. 接入DashScope text-embedding-v4原生接口，增加BM25/向量RRF、缓存、显式降级与严格失败；新增18项合同/融合测试，真实严格混合验收11/11通过。
9. 排查HTTP响应读取长时间等待的问题，增加请求总时限、stderr进度及Ctrl+C取消记录，并新增9项回归检查。
10. 增加React/Vite界面、本地SSE API和上游增量解析，区分待核验草稿与正式结果。新增11项Python、4项前端解析与8项浏览器验证；修正手机抽屉关闭问题，保留修正前截图。
